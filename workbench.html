Trigger placement uses the ideal waveform before noise. Single capture freezes a generated trace; it is not an actual acquisition. Displayed RMS and Vpp are numerical estimates over the visible window, and very fast signals can be visually aliased.

Signal model & measurement definition

The generator produces an ideal sine, triangle, square or 0-to-peak PWM waveform, with optional deterministic synthetic noise. The horizontal window is 10 × time/div and the full vertical range is 8 × volts/div. A trigger aligns an ideal rising or falling threshold crossing near 20% of the screen; a missing crossing is explicitly reported as no trigger. The displayed RMS is √(mean(V²)) across numerical points in the current window. A/B cursors report the signed time and voltage differences between two generated points. 1/|Δt| is only the inverse cursor separation, not the detected signal frequency.

Target pose / inverse kinematics ⌄

Target ready. Select Solve target or drag the plot.

Planar 3R chain: L1=140 mm, L2=110 mm, L3=75 mm. IK fixes the target (X, Y, φ), solves the two-link wrist geometry, and rejects unreachable or ±170° joint-limit solutions. No collision, torque, dynamic, or physical robot model is implied. Dragging changes the target; sliders provide a keyboard alternative.

Kinematic model & solution limits

Forward kinematics sums each link displacement: x = Σ Lᵢ cos(θ₁ + … + θᵢ) and y = Σ Lᵢ sin(θ₁ + … + θᵢ). For inverse kinematics, the wrist target is the selected tool position minus the final link projected along tool orientation φ. The remaining two links form a triangle solved using the cosine law. Each elbow branch is evaluated independently. Goals beyond the wrist workspace, or solutions requiring a joint outside ±170°, are rejected without silently moving to a different target. The displayed residual is caused by rounding computed angles to the 0.1° joint-slider resolution.
