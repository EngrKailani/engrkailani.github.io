Sensing uncertainty in a three-link robot.

How does synthetic measurement noise affect inverse-kinematics endpoint accuracy, and when does smoothing help? Run repeatable, paired multi-seed comparisons, inspect error and sensitivity charts, and export the generated observations and trial metrics.

Provenance: This is a supplementary educational experiment built with a public planar 3R geometry model. It is not a recovered result from my Honors leg project, a UR3e model, a NASA robot, or a physical measurement. No claim of experimentally validated control performance is made.

Run the experiment

A moving simulated tool target is corrupted with seeded Gaussian position noise. The unfiltered and exponentially smoothed targets are independently passed through the same inverse-kinematics solver, then compared across multiple deterministic noise seeds. Their forward-kinematics endpoints are compared with the true target using planar root-mean-square position error (RMSE).

Model, baseline, and limitations

  1. Ground truth: A deterministic, periodic planar target path with fixed tool angle of 0°. The model uses link lengths 140, 110, and 75 mm, chosen for illustration, not taken from a specific robot.
  2. Observation model: Independent Gaussian noise is added to x and y with the selected standard deviation. A seeded pseudo-random generator ensures repeatable runs.
  3. Baseline: The raw noisy target is solved with planar 3R inverse kinematics, then passed through forward kinematics.
  4. Comparison: Exponential moving-average smoothing, with weight α, is applied before the same inverse and forward kinematics steps. Low α can reduce jitter while introducing lag on a moving trajectory.
  5. Monte Carlo estimate: Repeated trials use distinct deterministic seeds with paired noise realizations for baseline and smoothing. A 95% percentile bootstrap interval is computed from 500 seeded resamples of the trial-level RMSE difference (unfiltered minus smoothed). This interval is illustrative for the specified simulation assumptions and is not a physical confidence interval.
  6. Metric: RMSE is the square root of the mean squared two-dimensional distance between model endpoint and the true target. Because inverse kinematics reconstructs the supplied positions, this tests the synthetic observation and filtering pipeline, not robot actuation or estimator performance under real sensors.

Interpretation: Results depend on the chosen path, noise level, seed, smoothing weight, joint limits, and idealized kinematics. No collisions, dynamics, actuator limits, temporal sampling rate, or independent physical calibration are modeled. A change in RMSE is not proof of improved real-world control.
