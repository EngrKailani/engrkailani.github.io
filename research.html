NASA MARSHALL / PERCEPTION AND MEASUREMENT

Lunar-regolith contamination image analysis

Developed a repeatable Fiji/ImageJ microscopy analysis pipeline with corrected illumination, threshold segmentation, and morphological filtering. Assessed deposited dust using complementary area-coverage and optical-darkening measures, along with particle-shape descriptors such as Feret diameter, aspect ratio, circularity, and solidity.

Additional analysis: Spatial sampling, confidence intervals, quality-control overlays, and structured CSV reports supported comparisons of contamination patterns. Original NASA imagery and measurements are not public.

UNR / HONORS SIGNATURE EXPERIENCE / FACULTY-MENTORED RESEARCH

Three-link human-leg dynamics

In a student-initiated Honors Signature Experience mentored by Dr. Sesh Commuri, developed a MATLAB Level-2 S-function for a planar three-link leg, computing foot position, Jacobian-mapped velocity, and a partial velocity- and gravity-related torque expression. The published source assembles an inertia matrix but does not include the joint-acceleration term in its returned torque.

Evidence boundary: The published source and an independent equation-consistency check support the kinematic description, not complete inverse dynamics, a recovered Simulink execution, physical gait measurement, or experimental validation.

Virtual vector network analyzer

In a student-initiated Honors Signature Experience mentored by Dr. Jihwan Yoon, developed a MATLAB two-port virtual VNA workflow for stepped-frequency radar analysis, with S-parameter visualization, a described SOLT calibration method, and Touchstone exports.

NASA MARSHALL / NON-NUCLEAR TEST ENGINEERING

Propulsion test modeling and software

Modeled extraction-force contributions in non-nuclear wire and channel analogs, including channel friction, spool-curl effects, capstan-type edge friction, and tare. Developed Python/PyQt6 tools for force-displacement visualization, CAN-based motor-control interfaces, trial sequencing, SQLite results storage, and hardware-free simulation.

Engineering contribution: Supported comparative test planning, analysis of force trends and measurement sensitivity, and identification of potential low-force instrumentation limits. This is a portfolio-level description of analog test engineering, not an experimental dataset or flight-hardware validation.

NASA MARSHALL / TEST-DATA AUTOMATION

Instron wire-pull test data processor

Developed an Excel/VBA batch-processing application for Instron force-displacement CSV files. Its documented workflow includes input and units detection, test-start identification, baseline correction, smoothing, breakaway and kinetic friction metrics, peak force, displacement, and model-derived comparisons.

Engineering contribution: Repeatable group statistics, data-quality checks, error logging, profile handling, formatted exports, and documentation for handoff. Internal test files and proprietary results are not distributed; this is not an independently calibrated measurement method.

Additional engineering case studies

EVIDENCE / OPEN PROBLEM / EVALUATION

How existing work informs the next research question

The evidence below is from completed engineering or simulation studies. Each evaluation is a proposed next step, not a reported experiment or NASA project commitment.

Manipulation geometry and robustness

Experience: Robotic-arm feasibility and group kinematic rank analysis show how workspace assumptions and robot configuration constrain tasks.

Open question: How reliably can tool motion be maintained as geometric assumptions and joint-state estimates become uncertain?

Proposed evaluation: Compare baseline and estimation-informed control in a generic simulation using tool-pose error and failed-motion cases.

Estimation under incomplete feedback

Experience: Three-link simulation illustrates model dependence; control laboratories documented differences between modeled and measured responses.

Open question: When do delayed or missing observations make model-based predictions unreliable?

Proposed evaluation: Predeclare synthetic sensor-noise and dropout scenarios and compare estimation error, recovery rate and control constraints.

Trustworthy sensing and verification

Experience: Regolith image analysis and RF measurement methods emphasize measurement processing and the need to separate illustrations from calibrated evidence.

Open question: Which uncertainties dominate decisions when perception or contact signals are only partially observed?

Proposed evaluation: Define traceable inputs, uncertainty assumptions and independent reference checks before claiming reliable task outcomes.

Reproducible educational example: Explore a seeded planar three-link sensing experiment that compares raw and smoothed synthetic observations across repeated trials, plots endpoint error, and exports numerical results. This is a separate teaching model, not a recovered result from the Honors research or physical robot testing.

04 / FUTURE RESEARCH QUESTIONS

Questions that can be measured and tested.

These questions outline experiments I would like to investigate; the measures below are proposed, not reported findings.

QUESTION / MANIPULATION

How does modeling error affect robotic manipulation accuracy?

Compare nominal and uncertainty-aware kinematic models under controlled link-length, encoder-offset, and joint-backlash perturbations. Begin with simulation and validate with hardware only if an appropriate test system becomes available.

Candidate measuresTool-position error (mm), orientation error (°), reachability, solver success rate
QUESTION / HUMAN–ROBOT OPERATIONS

When should a robot ask an astronaut for assistance?

Compare supervised and autonomy-first approaches for representative lunar or planetary tool-handling tasks, focusing on useful operator intervention rather than assuming fully independent operation.

Candidate measuresTask completion, operator interventions, response time, collision or constraint violations
QUESTION / SENSING & VERIFICATION

How does uncertain contact affect robotic tool handling?

In simulation, vary contact stiffness, friction, and tool alignment across disclosed ranges to compare controlled-contact strategies under the same task constraints.

Candidate measuresPeak contact force, slip events, task completion, constraint violations

Methodological intent: define baseline tasks and operating assumptions first, report uncertainty and failure cases, and distinguish synthetic evidence from instrumented tests.

05 / PROPOSED GRADUATE STUDY

Manipulation with incomplete feedback.

A future, independently proposed simulation study, not a completed experiment.

Research question. Under simulated sensing uncertainty, can estimation-informed control reduce robotic end-effector tracking error or task failures compared with an otherwise comparable nominal controller?

Evaluation principle. Report conditions where estimation helps and where model mismatch or delayed feedback limits its benefit. This independent study is separate from my NASA internship work.

01 / PROPOSED METHOD

Generic simulation

Use a non-project-specific manipulator model with clearly disclosed assumptions. Introduce synthetic noise, delayed measurements, and intermittent feedback. Do not use or imply unreleased NASA geometry, test conditions, or data.

02 / COMPARISON

Reference versus uncertainty-aware approach

Compare a fixed-model control baseline with an estimation-informed alternative over the same predeclared tasks and disturbance cases. Report when either approach fails, not only when it succeeds.

03 / CANDIDATE MEASURES

Quantitative evaluation plan

Evaluate RMS and peak tool-position error, recovery rate following simulated feedback loss, constraint violations, and computation time. These are proposed metrics—not measured results or performance targets.

Public-data boundary: The proposed simulation would use a generic manipulator model and synthetic sensing disturbances, not unreleased NASA geometry, data, or results. See the NASA case study and affiliation statement. Read the proposed independent experiment protocol, including comparison baselines, candidate metrics, and release criteria. The protocol is not a completed research result.
