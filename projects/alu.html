PROJECT 07 / 16

For this VHDL coursework project, I implemented a registered four-bit ALU with ripple-carry arithmetic and an XOR path. Switches and a pushbutton select operations, while LEDs and seven-segment displays show the outputs. The case study documents integration issues with FPGA pin mapping and display drivers.

Engineering details

Challenge

Implement multiple arithmetic and logic operations with a one-clock-cycle registered interface and clearly observable hardware outputs.

Approach

Combine a four-bit ripple-carry adder, operand selection logic, an XOR path, input/output flip-flops and a seven-segment decoder. Test pass-through, increment, addition, subtraction and XOR operations with representative switch settings.

Tools

VHDL, ripple-carry adder, sequential logic, FPGA I/O mapping, binary LED readout, seven-segment display.

Documented outcome

The implemented design updated outputs after a clock edge. Pin assignments and competing LED drivers required debugging; an exhaustive timing or hardware-verification record is unavailable.
