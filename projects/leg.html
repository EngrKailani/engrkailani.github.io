The MATLAB/Simulink model links three-joint motion to foot-position and velocity estimates and simplified joint-torque calculations. This student-initiated Honors project examined modeling methods, not a physical assistive device.

Engineering details

Challenge

Calculate the position, velocity, and dynamic response of a three-joint biomechanical system.

Approach

Use a MATLAB S-function within Simulink, Jacobian kinematics, and Newton–Euler dynamics to compute joint torques.

Tools

MATLAB, Simulink, S-functions, Jacobian mapping, and simplified dynamic modeling.

Model interpretation / simulation, not gait measurements

From joint motion to simulated foot position and torque

The original MATLAB/Simulink work couples kinematic relationships with simplified linked-body dynamics. The sequence below explains the modeling method; it is not an independently calibrated description of human walking.

1. Position from joint angles

Planar link lengths and cumulative joint angles define the modeled foot endpoint relative to the hip. Forward kinematics establishes the position before velocities or forces are considered.

2. Velocity from the Jacobian

The Jacobian maps joint-angle rates to foot velocity. This relates local joint motion to the endpoint motion used by the simulation.

v = J(q) q̇

3. Simplified joint dynamics

The dynamic model considers inertia, velocity-dependent interactions and gravity-related torque terms. Its output depends on the assumed link and mass parameters.

Reproducibility boundary: The public model repository permits inspection of code and assumptions. Quantified numerical accuracy would additionally require declared link parameters, reference trajectories and comparison against measured motion, which are not provided here.

Documented outcome

A faculty-mentored, student-initiated simulation of articulated leg kinematics and simplified dynamics. No assistive device was built, and no physical validation is claimed.

Evidence & limitations

Public source you can inspect: the original MATLAB code file and repository documentation. The Honors research summary records the faculty-mentored scope.

Evidence boundary: Public code supports inspection of the modeling approach, not experimental accuracy. No measured gait comparison, physical prototype, raw experiment dataset, or independent test evidence is represented where unavailable.
