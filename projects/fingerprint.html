PROJECT 04 / 16

Our four-person embedded-systems group built a standalone fingerprint identification system around an STM32F767ZI and an optical sensor. Instead of relying on the sensor library, the firmware uses manually constructed UART command packets and response parsing. A guided enrollment process lets users register prints, while green and red LEDs indicate matching results.

My contribution / team context

Member of a four-person embedded-systems team building a fingerprint identification prototype.

Engineering challenge

Coordinate reliable sensor enrollment, fingerprint searching, serial packets, and clear feedback for multiple users.

Methods and approach

Configure two UART channels, implement protocol framing and acknowledgment handling, map 24 template IDs to four users, and drive status LEDs and terminal messages.

Tools and environment

STM32F767ZI, embedded C, UART packet protocol, sensor integration, GPIO.
