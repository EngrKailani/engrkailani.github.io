Engineering details

Challenge

Make gesture recognition useful for controlling lighting in an intuitive way.

Approach

Track hands with MediaPipe and map gesture states to lighting controls and a browser preview.

Tools

JavaScript, MediaPipe, Node.js, webcam tracking, RGBW lighting.

Recovered gesture-control prototype

The original source and manual are still available. A browser uses MediaPipe hand landmarks, custom gesture classification, frame-based stabilization, and an RGBW preview. An optional local Node.js bridge maps eight approved keys to configured Casambi lighting scenes. The recovered software's functionality is established by source inspection; live camera accuracy and physical lighting response have not been independently retested.

Engineering recovery and verification

I reconstructed the gesture-state and scene policy as a separate offline JavaScript module and verified 11 synthetic behavior cases. The recovery package includes source architecture, frame thresholds, timing rules, eight scene mappings and a security review. The original HTTP /control endpoint does not authenticate callers, so the bridge must be secured before exposure on an untrusted network or use in a real deployment.

Evidence & limitations

The recovered architecture, gesture mapping and offline tests describe source-level behavior. Live webcam classification accuracy and physical lighting response were not independently retested; the local control bridge must be secured before exposure to untrusted networks.
